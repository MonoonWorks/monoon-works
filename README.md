# Monoon Works

An independent software studio website for Simple PDF, Simple Notes, Academia Flow, and Academia Archive.

## Preview

Open `index.html` in a browser. The page is self-contained, with embedded app icons, product screenshots, and fonts, and needs no build step.

Each app has a dedicated product view, reachable from its card or hero icon, with an expandable screenshot and a feature overview. Screenshots use original example content.

English is the default language. The language control provides Korean.

The interactive reading, writing, planning, and archive examples are website demonstrations, not connections to the apps. No installers, purchases, analytics, or user data collection are included.
