# Monoon Works

The Monoon Works product website, featuring Academia Flow, Academia Archive, Simple PDF, Simple Note, and Simple Search. Includes real desktop screenshots, English/Korean content, and private-pilot contact information.

The self-contained `index.html` needs no build step. The site is published through GitHub Pages at https://monoonworks.com/.

## Product evidence

Nine real desktop captures show the Flow reading library, research journal, manuscript workspace, weekly planning, appearance settings, Archive library, PDF body/endnotes, and both Note editing modes. Flow uses English and Academic Neutral in an isolated Monoon Demo workspace. The planner contains twelve activities across reading, research, writing, class, meeting, event, administration, and study.

Demo manuscripts, notes, and schedules are fictional. Bibliographic examples are ten published works selected from Zotero; private research notes and attachments are excluded. Archive uses its current Korean interface with English demo collections and bibliographic records. Descriptions distinguish current private-pilot capabilities from planned Claude API work.

The page includes detailed English/Korean product explanations, product navigation, expandable Flow screenshots, and theme information.

## Historical website

An earlier website, including a game showcase, is preserved in commit `76db0cde8a7bf5df0d937f19e36755d092784e49`. The current homepage focuses on research products and their existing capabilities; planned Claude API features are identified as planned.
